# Restudio Public Signing Keys

This directory contains public cryptographic keys used to verify official Restudio security packages and repository metadata.

Only public keys are stored in this directory.

Private signing keys must never be published, uploaded, or distributed through this repository.

Before trusting a public key, users should verify its fingerprint through an official Restudio communication channel.

## Key Management

Public keys are maintained by Restudio Software Laboratories.

Key rotation, expiration, and revocation procedures will be documented as the security infrastructure develops.
